Déposez un fichier, il saura se réparer

Le fichier texte est découpé en blocs, protégé par un code de Reed-Solomon et signé par un CRC-32. S’il est abîmé plus tard, il peut être restauré.

Fichiers déposés

Chaque fichier est vérifié à l’ouverture. Un carré représente un bloc de données.
